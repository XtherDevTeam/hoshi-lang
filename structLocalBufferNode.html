LocalBufferNode Struct Reference

Local buffer node for the local buffer. Each node contains a fixed number of entries (ELYSIA_BACON_LOCAL_BUFFER_SIZE) and a reference count. The local buffer is used to store objects that are not yet finalized and are not yet part of the global buffer. The local buffer is thread-local, meaning that each thread has its own local buffer. Detailed Description

Local buffer node for the local buffer. Each node contains a fixed number of entries (ELYSIA_BACON_LOCAL_BUFFER_SIZE) and a reference count. The local buffer is used to store objects that are not yet finalized and are not yet part of the global buffer. The local buffer is thread-local, meaning that each thread has its own local buffer. The local buffer is used to reduce the overhead of allocating and deallocating objects in the global buffer.
